# 0190 — Plural references bind exact local conversational sets

Status: Implemented bounded clean-platform slice; locally verified. Development
release evidence is recorded separately; general language accuracy remains Partial.

## Decision

Extend Context's local discourse state and existing semantic graph algebra. A
bounded account-local frame records exact members, optional event/collection,
membership witnesses, completeness, and last-used sequence/time. It is not a
principal, organization, sharing group, provider request, or alternative graph.
Frames survive local reload and canonical-ID remapping but are not graph publication
data, synchronized cross-device conversation, or reusable Path contents.

Inclusive pronouns select the latest established participant event containing the
speaker. Other plural references select the latest exact set. Exclusions operate
on the statement without deleting original membership; complements can use the
retained parent set. Singular shared possessions require one exact common child.
Counted events may create explicitly unnamed local members, never guess identities
of known places/things. Incomplete counts and paged query results cannot authorize
full-set distribution. Merely mentioning people does not construct a collective.

The current policy retains twelve frames, at most 64 members each. Thirty minutes
without use or ten unrelated successful inputs makes a frame dormant. A ten-minute
revision-bound confirmation resumes the original request, not a new interpretation
of “yes”. Missing/foreign/protected members, stale witnesses and scope changes
cannot silently reduce the set or retarget another group. This is deterministic
context expiry, not a general topic-change classifier.

Mutation `resolve.scope` optionally binds `members` or `event` from a complete
captured reference. Facts/classifications distribute atomically; links and nested
scalar resolution do not imply Cartesian products. All member guards and existing
effect limits remain enforced. Event time changes the same occurrence, not each
person; subsets cannot rewrite a full-group event. No ordinary ownership fact
grants managed-entity control, sharing authority or protected access.

The bounded language-data recognizer, learned Paths and shooting-star review all
use this resolver and the existing atomic transaction. Failed review may nominate
ordinary group evidence; checkpoints freeze the original frame to prevent delayed
advice using a different later group. Exact response references drive existing
Inspector/Column attention. The API only transports untrusted proposals, and
Compute/JPL/provider execution and protected plaintext boundaries are unchanged.

## Evidence and limits

Clean-platform decision 0138 describes schemas, tests and limits. Deterministic
dialogue tests cover exclusions, complementary sets, event/member effects, shared
possessions, unnamed/named collections, expiry, atomic rejection, remapping,
reusable Path execution and review context. Chromium exercises the worker/API/
publication/reload boundary without an adviser call. This is not unrestricted
pronoun understanding, remote bulk mutation, cross-device discourse, or live-model
success-rate evidence. Unsupported syntax and ambiguity still need the existing
adviser or clarification.
