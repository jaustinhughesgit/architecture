# 0181 — Exact response references drive Inspector attention

Date: 2026-09-16

The clean platform extends ordinary response provenance with bounded exact
entity/version and relation/version references. Profile reads, learned reads and
comparisons, lists, descriptions, graph queries, unchanged assertions and ordinary
Compute/ArrayLogic results can drive the same Inspector spotlight as mutations.
This repairs the gap where a correct name answer had no relationship witness.

Producers capture references during execution; presentation never infers identity
from prose. Current graph versions, owner scope and existing scene admission remain
mandatory. Publication remaps identities. Managed ordinary reads use the same local
attention event as saves. Protected traces gain no ordinary reference/value channel;
no permission, daily activity, model call or graph mutation is implied. Generic
responses without graph referents do not invent entities. Session dismissal and
reload continue to suppress historical attention.

Status: implemented in source; see clean-platform decision 0129 for verification
and release evidence. This supersedes decision 0180's exclusion of no-op results.
