# 0156: Data-defined ordinary semantic growth

- Status: Accepted, bounded implementation
- Date: 2026-09-11

## Decision

The clean platform adds the missing semantic-composition tier between a one-operation Path and new trusted source code. A versioned immutable package stores anchored complete syntax and bounded single-assignment resolve/create/fact/link/classify logic. These are data compositions of the existing ordinary graph transaction, not per-sentence apps or executable JavaScript. Exact local identity, authority, whole-operation validation and persistence remain mandatory.

Installed definitions execute locally. Missing ordinary inputs search shared definitions; when existing operation learning is insufficient, the configured adviser proposes grounded multi-step logic without receiving the graph. Browser proof commits all clauses or none. Event occurrences retain their own context; pair-specific relationship facets retain qualifiers without moving them onto people globally. A recipient resolves the shared pattern against its own graph; creator values, concrete IDs and permissions are not reusable parameters.

The API stages only its own compiled proposals in the existing private artifact bucket. After successful browser persistence, an authenticated exact interaction/hash acknowledgement promotes that candidate. A durable local outbox retries share failures after reload without repeating effects. Public callers cannot upload arbitrary packages. Candidate admission, immutable-byte/hash validation, schema/policy guards and local proof constrain operational effects; they do not prove arbitrary semantic correctness or constitute comprehensive DLP. Lowercase concept-versus-private-content classification still depends on interpretation quality.

Cross-layer changes include an optional composition tier/semantic package on the proposal contract, authenticated semantic search/accept endpoints, local package/outbox state, and optional semantic-package provenance on graph-compose traces. Canonical fact publication, protected data boundaries, Compute/JPL and bucket IAM stay unchanged. Local reset preserves definitions/outbox and its browser path requires pending sharing to finish. No reset is performed by this release.

Composition advice uses low reasoning with the existing token/time ceiling after the first live medium-reasoning attempt exhausted the output budget. Optional fixed-text compiler diagnostics and typed repair categories return no captured values or local graph details. One-operation advice remains unchanged. The failed live round is retained as failure evidence, not successful coverage.

The next live round drove an explicit exclusive-end token contract, abstract compiler-tested role/event examples, and directed-edge-independent object/facet connectivity. Scalar and classification values cannot bridge orphaned objects. Invalid local plans can trigger a bounded typed repair without exposing graph errors to the adviser; missing or ambiguous references remain user clarifications.

Further live replay repaired a general identity bug: an outgoing object relation cannot make its subject an alias for its target. Connectivity feedback is separately typed; abstract compound-reference/context examples preserve the complete owner scope and address created objects through registers, not scalar labels. Context assertions may be scalar values or structured noun/descriptor branches; evaluation checks meaning on the exact branch rather than requiring one display label.

Fresh users automatically prove unambiguous shared one-operation Paths as well. Explicitly archived local Paths retain the restore/new-generation choice. The automatic semantic tier is limited to affirmative ordinary graph statements; external actions, negation, uncertainty, arbitrary reads, deletion, protected execution and new interpreter primitives remain unsupported. Pattern and logic are fields in one artifact; independently shared semantic subprograms, stronger quality promotion/revocation, exhaustive retrieval and broad multilingual coverage remain incomplete.

## Status

Implemented bounded graph-composition foundation; general capability growth remains Partial. Initial policy grammar is English. No 95% claim. Ten deterministic multi-step scenarios, atomic failure, hash/identity/auth boundaries and browser cross-account/offline/outbox behavior have tests. Actual provider/deployment evidence must be recorded separately from fixture results in the capability catalog and `onevar-platform/docs/testing/semantic-growth.md`.
