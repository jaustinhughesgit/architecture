# 0188 — Column is an exact response projection

Status: implemented browser-local slice; not deployed.

The clean-room product adds Column beside CLI and Inspector, sharing current
authorized Context, peer revalidation, managed scope and app workbench authority.
Columns traverse exact directed subject/facet/value relationships. Reverse counts
never include marketplace suggestions or navigation shortcuts as fabricated edges.
Terminal rows stay in their parent; mobile renders the current column only.

Existing response references and committed effect receipts select the landing:
a single affected chain reveals its last entity; multiple branches open their
lowest common parent. Shared-value routes prefer response witnesses. Workflow
attention aggregates committed steps from the same current-session run. Rendering
never parses response prose as identity and never adds a language-model call.

Navigation is transient, canonical IDs are remapped, and revoked references
disappear against the latest authorized projection. App execution, purchases,
managed privileges and zero-trust assets retain their existing boundaries.
This is a browser projection change, not a new schema or persistence plane.

Product decision 0136, column-model tests and Column browser acceptance describe
the implemented slice. No deployment, reset or production-scale claim is made.
