# 0180 — Bounded query evidence and result attention

Date: 2026-09-16

The existing semantic-query learning loop may receive up to 48 ordinary owner-local
nodes and 48 facts, bounded to 10,000 serialized characters. Lexical seeds plus
one connected hop are represented with temporary pseudonyms, direct property
edges and optional facets. Foreign/hydrated records, canonical IDs and sealed
content are excluded. Evidence is advisory and incomplete; the model proposes
only a reusable strict query definition, proven locally before activation/share.
Known valid queries remain local. No protected or managed-plaintext route is added.

An empty learned query that explicitly names a unique subject and an existing
property can request the existing bounded repair loop. A successful replacement
retires only locally overlapping queries that reproduce that signal; immutable
archive/history remains. This is a bounded heuristic, not comprehensive semantic
validation or a 95% success claim. Genuine empty answers outside this condition
remain valid, and retrieval ambiguity is never resolved by ranking alone.

Extend temporary Inspector spotlight to exact current read witnesses and applied
ordinary Compute/workflow effect receipts. Current-session endpoints become
readable; unrelated admitted dots shrink to 30%. No-op/failed effects, stale read
witnesses and old sessions do not create attention. Manual dismissal, permissions,
scene admission, camera and graph remain unchanged. This supersedes decision
0179's blanket read exclusion, not the daily Sunburst activity policy.
