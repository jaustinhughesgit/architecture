# 0185: Repairable interpretations re-enter semantic learning

Status: Implemented bounded source slice; deployment and live-model accuracy not
established by the deterministic tests in this change.

The clean runtime distinguishes an inapplicable learned definition from a genuine
missing entity. Local and shared candidates are proved without persistence before
successful meanings are compared. An incompatible type guard or unparsed phrase
can reach fresh semantic learning; multiple applicable meanings, proven missing
references, permissions and unsupported modalities still stop safely.

The existing mutation resolve primitive adds optional nullable `within`, referring
to a prior parent register. It resolves an existing captured child/facet under that
exact parent without introducing it. Generated Paths can therefore decompose owner
wording into reusable data rather than requiring domain-specific source branches.
Explicit creation, properties and location still compose existing graph primitives.

Only coarse type/reference-syntax repair codes extend the existing proposal API.
No extra graph or protected data goes to the adviser. The same three-attempt limit,
local atomic proof, versioned package hash, persistence and exact sharing
acknowledgement apply. Old artifacts retain their bytes; inappropriate candidates
for one type are not deleted for other types. General language accuracy remains
Partial. Scoped programs currently use ordinary fact descriptions instead of
unsupported narrative inversion.

Implementation, limits and fixture evidence: product decision 0133 and runtime,
API and browser semantic-learning tests in `onevar-platform`.
