# 0140: Inspector folds classifications and groups focus branches

Status: Accepted; supersedes decision 0138's whole-ring slot optimizer.

## Decision

Inspector V2 hides a terminal `value` point only when its incoming relations are exclusively `kind` from non-value subjects. Its original exact record and relations remain in Context and its kind remains visible in the subject's facts surface. No names or identities are merged: two actual bicycles remain two points. Values with another semantic role or outgoing structure remain independent. Already-authorized peer slices use the same projection without additional disclosure. Folded classifier nodes cannot supply invisible relevance shortcuts.

An exact-edge breadth-first tree assigns connected descendants contiguous angular sectors at their unchanged relevance radius. Previous session positions seed orientation relative to a new focus. Cycles choose a deterministic shortest-path parent; disconnected remote/marketplace candidates retain separate placements. Layout may use bounded exact relations omitted by the rendered degree cap, never synthetic associations. The 96-node/160-edge layout limit and unchanged-layout oversize fallback prevent unbounded work.

Only identifiable endpoint pairs display a line, except during explicit endpoint dragging. Long non-focus wiring stays hidden until local exploration. Overlapping endpoints do not produce inverted lines. Existing endpoint masks, collision animation, colors, gestures and authority remain unchanged. V1 remains available. No Context migration, deletion, identity change, API schema, server layout, LLM call or persistent coordinates are introduced.

## Proof and boundaries

Pure tests cover classification folding, preserved underlying details, distinct same-name objects, other semantic uses, hidden classifier shortcuts, branch locality, relevance radius preservation, deterministic input ordering, previous-focus bearings, cycles, disconnected points and bounded fallback. Browser regression covers one possession point and its facts, focus change with readable wiring, reload and two distinct same-name possessions. Existing workbench binding/run, zoom, keyboard and mobile tests remain required. Product implementation and layer ownership are recorded in `onevar-platform` decision 0083 and the Inspector layer guide. Production-scale global graph layout is not claimed; only the bounded visible scene is laid out.
